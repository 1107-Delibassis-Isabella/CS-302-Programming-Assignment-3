Project goals:
1. Build fundamental data structure stack implemented by using a dynamically allocated linked structure from scratch
2. Build fundamental data structure queue implemented by using a dynamically allocated linked structure from scratch

Required Testing: 
The results of the required testing section are in the testing.txt file with the results that have been produced for all of the following including the invalid inputs

Details for how to run the code: 
This is in VS code using C++ language
In order to make, you can type in "make"
In order to make clean the code, type in "make clean"
To run the code, you must type "./PA3".

Time Complexity: 
The time complexity of the LinkedStack::push is O(1)    because there are no loops

The time complexity of the LinkedStack::pop is O(1)     because there are no loops

The time complexity of the LinkedQueue::enqueue is O(1)     because there are no loops

The time complexity of the LinkedQueue::dequeue is O(1)     because there are no loops

The time complexity of the Tokenization is O(N)     because there is only one loop

The time complexity of the Infix to postfix conversion is O(N)      because there is only one loop overall and although there are other loops within, they are not going from the beginning to end

The time complexity of the Postfix evaluation is O(N)   because there is only one loop and no nested loops inside
